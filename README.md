# 1D2S 称号エディタ

譜面フォルダに置く `title.json` を、ブラウザ上で作成・検証・出力できる Web ツールです。  

## できること

- 曲名を入力して `title.json` を作成
- 称号の追加・複製・削除・並べ替え・検索
- 称号ID・称号名・プレートID・説明の編集
- 隠し称号の設定
- 単一譜面・複数譜面の条件設定
- プレイ条件・難易度・オプション条件の設定
- ゲーム実装に合わせた入力チェック
- 説明文の自動生成
- テンプレートから複数の称号をまとめて追加
- 整形済み `title.json` のコピー・ダウンロード・フォルダ保存

入力内容はブラウザ内だけで処理されます。

## 使い方

1. **曲名**を入力します。
2. **称号を追加**するか、**テンプレートから追加**を選びます。
3. 称号名・プレートID・プレイ条件・難易度を設定します。
4. 必要なら「隠し称号にする」をオンにします。
5. 複数譜面条件の場合は「複数譜面」に切り替え、対象譜面を追加します。
6. 必要に応じて「説明」の自動生成をオンにします。
7. 右側の「検証」でエラーがないことを確認します。
8. **書き出す**から `title.json` をダウンロード・保存します。
9. 単一譜面称号は曲のフォルダへ、複数譜面称号は `songs` 配下の任意の場所へ `title.json` を置きます。

## 称号の設定

### 称号ID

称号を追加すると自動で設定されます。  
全曲を通じて一意になるようにしてください。空文字や重複は出力できません。

### 称号名

ゲーム内に表示される名前です。  
同じ名前の称号を複数作ることもできます。

### プレートID

称号プレートの種類です。既定の候補から選ぶか、「カスタム」を選んで自由入力できます。  
空の場合は既定のプレート `00` が使われます。

### 説明

称号獲得時に表示される説明文です。  
「自動」をオンにすると、曲名・難易度・プレイ条件・オプション条件から文章を生成します。手動で編集したい場合は「自動」をオフにしてください。

### 隠し称号

「隠し称号にする」をオンにすると、その称号は獲得するまで `title.db` に登録されません。  
ゲーム内の称号一覧にも表示されず、獲得条件を満たした時点で獲得済みとして登録されます。

出力時は、隠し称号のみ `"Hidden": true` が追加されます。

### プレイ条件

| プレイ条件 | 意味 |
|---|---|
| `Play` | プレイする |
| `Clear` | クリアする |
| `FullCombo` | フルコンボする。可（OK）は許容 |
| `DonderfulCombo` | ドンダフルコンボする。不可・Miss・可がすべて 0 |

### 難易度

- 全難易度（Any）
- かんたん
- ふつう
- むずかしい
- おに
- おに（裏）

## 複数譜面条件

「獲得条件」の「複数譜面」を選ぶと、複数の譜面を対象にした称号を作成できます。  
指定したすべての譜面で条件を満たすと獲得になります。

各譜面には以下を設定します。

| 項目 | 内容 |
|---|---|
| 譜面パス | `songs` フォルダからの相対パス。例: `PackA/song1/song.tja` |
| 難易度 | かんたん〜おに（裏） |
| プレイ条件 | プレイ / クリア / フルコンボ / ドンダフルコンボ |
| オプション条件 | その譜面専用の演奏オプション条件 |

譜面パスの区切りは `/` を使用し、`.tja` ファイルまで指定してください。  
複数譜面称号の `title.json` は、TJAと同じ階層でなくても `songs` 配下ならどこに置いても読み込まれます。

単一譜面称号をパックとして定義したい場合は、複数譜面モードで譜面を1件だけ指定してください。

## オプション条件

必要に応じて、演奏オプションの条件を追加できます。

| プロパティ | 演算子 | 値 |
|---|---|---|
| `ScrollSpeed` | `>=` `<=` `!=` `=` `>` `<` | 0.5〜4.0 |
| `Swap` | `=` `!=` | `true` / `false` |
| `Doron` | `=` `!=` | `0` なし / `1` ドロン / `2` ステルス |
| `Random` | `=` `!=` | `0` なし / `1` きまぐれ / `2` でたらめ |

例:

```text
ScrollSpeed>=2.0
Swap=true
Doron=1
Random!=0
```

## 説明の自動生成

「自動」をオンの間は、次の形式で説明を生成します。

```text
{曲名}を{難易度表現}(オプション「{オプション名}」で){プレイ条件名}
```

難易度が全難易度（Any）の場合は「いずれかの難易度で」になります。

例:

```text
サンプル曲を難易度おにで(オプション「スクロール速度2.0以上」で)フルコンボ
サンプル曲をいずれかの難易度でプレイ
```

オプション条件が複数ある場合は「A・B」のように連結されます。

## テンプレート

| テンプレート | 内容 |
|---|---|
| プレイ | プレイ / プレートID 02 |
| クリア | クリア / プレートID 02 |
| フルコンボ | フルコンボ / プレートID 03 |
| ドンダフルコンボ | ドンダフルコンボ / プレートID 03 |
| おに・クリア～ドンダフルコンボ称号 | おにのクリア / フルコンボ / ドンダフルコンボ（ex_silver / ex_gold / ex_dfc） |
| おに＆おに（裏）・クリア～ドンダフルコンボ称号 | おに・おに（裏）のクリア / フルコンボ / ドンダフルコンボ（ex_silver～ex_dfc / ura_silver～ura_dfc） |

「おに・クリア～…」「おに＆おに（裏）・…」のテンプレートで追加される称号名は、すべて入力中の曲名になります。

## 出力について

- ファイル名は `title.json` 固定です。
- 文字コードは UTF-8（BOM なし）
- 改行は LF
- インデントは半角スペース 2 つ
- 末尾に改行が 1 つ入ります。
- 隠し称号のみ `Hidden` が出力されます。通常の称号には `Hidden` は付きません。
- 複数譜面称号は `Condition.Type: "Multi"` と `Requirements` 配列で出力されます。

エラーがある場合は出力できません。警告がある場合は内容を確認したうえで出力できます。

## データの扱い

- 入力内容はブラウザ内だけで処理されます。
- 下書きはブラウザに自動保存されます。ただし、ブラウザのデータ削除などで消える場合があります。
- 必要なデータは `title.json` として書き出して保管してください。

## 対応ブラウザ

- Google Chrome / Microsoft Edge の最新版
- Firefox / Safari、他ブラウザでも編集・出力は可能です。

曲のフォルダへ直接保存する機能は、File System Access API に対応したブラウザで利用できます。  
非対応のブラウザでは「ダウンロード」から `title.json` を保存してください。

## 注意

- 単一譜面称号の `title.json` は、対象の曲の譜面フォルダに置いてください。
- 複数譜面称号の `title.json` は、`songs` 配下であれば場所を問いません。
- 既存の `title.json` を上書きする場合は、必要に応じてバックアップを取ってください。
- ゲーム側の仕様変更により、条件判定や対応項目が変わる場合があります。
